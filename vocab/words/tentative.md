# tentative

- **IPA / 音标:** /ˈtentətɪv/
- **Pronunciation tip:** TEN-tuh-tiv；重音在 TEN；末音节 /tɪv/ 轻短
- **Etymology / 词源:** 拉丁 *tentare* / *temptare*「尝试、试探」→ 中世拉丁 *tentativus* → *tentative*（带「先试着定、还能改」的意味）
- **POS:** adjective（副词 *tentatively*）
- **Gloss (EN):** not final; provisional; subject to change
- **释义 (ZH):** 暂定的；未敲定的；可改的
- **Register:** formal / neutral（会议、日历、结论保留）

## Collocations / 固定搭配（别直译）
- USE: *a tentative timeline*; *mark … as tentative*; *a tentative hold/conclusion*; *tentatively scheduled*
- AVOID: 日历里用 *busy* 表示「暂定」；*temporary time* / *not sure date*；别混 *attentive*（专心的）

## Why this chunk
- *a tentative timeline* = 可改的时间表，保留诚实空间；不是 *possible timeline*（只说有可能）。
- *mark … as tentative* = 日历/邀请上的状态标签；不是 *mark as busy*（那表示你没空）。
- vs *provisional*：接近，但会邀/日历职场英语更常说 *tentative*。

## Rewrite prompt
弱句：「上线时间还没定死，先随便写个日期，日历先占上。」  
→ 必须用 `a tentative timeline` 或 `mark … as tentative` 写出可发的会议/Slack 英文。

5. 稳定后再考虑 transfer（如客户 kickoff 邮件）

## Pitfalls
- 错拼少见，但副词别漏：*tentatively*
- 日历 *tentative* ≈ 待定接受，≠ *busy*
- 名词感表达优先用 chunk，不要只丢光杆 *tentative*
